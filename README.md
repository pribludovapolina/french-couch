# Cahier de français

Дневной план изучения французского (октябрь 2026) с личным прогрессом. Сайт на Node.js, данные в файле SQLite, вход по логину и паролю.

## Что где лежит

| Путь | Что это |
|---|---|
| `server.js` | Сервер: отдаёт страницу, регистрация, вход, сохранение прогресса |
| `db.js` | База SQLite и её схема; таблицы создаются сами при первом запуске |
| `public/index.html` | Вся страница сайта |
| `public/data/month1.json` | Уроки октября; отдаются только вошедшим |
| `content/` | Исходники уроков и сборщик `build_data.py`, который пишет `public/data/month1.json` |
| `scripts/reset-password.js` | Сброс забытого пароля владельцем сайта |
| `render.yaml` | Описание сервиса и диска для Render |
| `data/` | Локальный файл базы; в git не попадает |
| `_private/` | Твой прогресс, выгруженный из старого сайта; в git не попадает |

## Таблицы в базе

- `users`: логин и хэш пароля (scrypt). Сам пароль не хранится.
- `sessions`: кто сейчас вошёл. Сессия живёт 60 дней и продлевается, пока сайтом пользуются.
- `progress`: отметки шагов и ответы по дням, один документ на человека.
- `items`: карточки, тексты домашек, вставленные тексты и сохранённые переводы слов.

## Деплой на Render

База лежит в файле, поэтому сервису нужен постоянный диск. Диск у Render есть только на платных тарифах: на бесплатном все файлы стираются при каждом засыпании и деплое, и аккаунты с прогрессом пропадали бы. В `render.yaml` поэтому стоит младший платный тариф и диск на 1 ГБ.

1. Выложи эту папку в приватный репозиторий на GitHub.
2. В Render: New → Blueprint → выбери репозиторий. Render прочитает `render.yaml` и создаст сервис с диском. Для платного тарифа в аккаунте Render должна быть привязана карта.
3. Дождись сборки и открой адрес вида `https://cahier-de-francais.onrender.com`.
4. Зарегистрируйся. Чтобы перенести прогресс со старого сайта, нажми на свой логин в шапке → «Загрузить из файла» → выбери файл из `_private/`.

Регистрация открыта всем, кто знает адрес. Чтобы закрыть её кодом, добавь в Render переменную `INVITE_CODE`.

Render делает снимок диска раз в сутки и хранит снимки не меньше семи дней. Свою копию прогресса каждый может скачать кнопкой «Скачать прогресс» в панели аккаунта.

## Локальный запуск

```bash
npm install
```

```bash
npm run dev
```

Сайт откроется на http://localhost:3000, база создастся в `data/cahier.db`.

## Переменные окружения

| Имя | Зачем |
|---|---|
| `DB_FILE` | Путь к файлу базы. По умолчанию `data/cahier.db`; на Render `/var/data/cahier.db` на диске |
| `INVITE_CODE` | Если задан, регистрация только по этому коду |
| `MAX_USERS` | Предел числа аккаунтов, по умолчанию 200 |
| `PORT` | Порт; Render задаёт его сам |

## Забытый пароль

Почты у аккаунтов нет, поэтому пароль сбрасывает владелец. На Render открой у сервиса вкладку Shell и выполни:

```bash
node scripts/reset-password.js ЛОГИН
```

Скрипт напечатает временный пароль и завершит все сессии этого человека.

## Пересборка уроков

Правки вносятся в `content/*.py`, затем:

```bash
python3 content/build_data.py
```

Нужен пакет `openpyxl`. Расписание берётся из `content/plan.xlsx`.
