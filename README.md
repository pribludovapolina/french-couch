# Cahier de français

Дневной план изучения французского (октябрь 2026) с личным прогрессом. Сайт на Node.js, данные в базе Turso, вход по логину и паролю. Рассчитан на бесплатный тариф Render.

## Что где лежит

| Путь | Что это |
|---|---|
| `server.js` | Сервер: отдаёт страницу, регистрация, вход, сохранение прогресса |
| `db.js` | Подключение к базе и её схема; таблицы создаются сами при первом запуске |
| `public/index.html` | Вся страница сайта |
| `public/data/month1.json` | Уроки октября; отдаются только вошедшим |
| `content/` | Исходники уроков и сборщик `build_data.py`, который пишет `public/data/month1.json` |
| `scripts/reset-password.js` | Сброс забытого пароля владельцем сайта |
| `render.yaml` | Описание сервиса для Render |
| `data/` | Локальный файл базы для запуска на своём компьютере; в git не попадает |
| `_private/` | Прогресс, выгруженный из старого сайта; в git не попадает |

## Таблицы в базе

- `users`: логин и хэш пароля (scrypt). Сам пароль не хранится.
- `sessions`: кто сейчас вошёл. Сессия живёт 60 дней и продлевается, пока сайтом пользуются.
- `progress`: отметки шагов и ответы по дням, один документ на человека.
- `items`: карточки, тексты домашек, вставленные тексты и сохранённые переводы слов.

## Деплой на Render

У бесплатного сервиса Render нет постоянных файлов, поэтому база живёт отдельно, в Turso: `libsql://fr-pribludovapolina.aws-eu-north-1.turso.io`. Адрес уже вписан в `render.yaml`, а токен доступа задаётся только в настройках Render.

1. В Turso открой страницу базы и создай токен (Create Token) с правом чтения и записи.
2. Выложи эту папку в приватный репозиторий на GitHub.
3. В Render: New → Blueprint → выбери репозиторий. Render прочитает `render.yaml` и спросит значение `TURSO_AUTH_TOKEN`: вставь токен из шага 1.
4. Дождись сборки и открой адрес вида `https://cahier-de-francais.onrender.com`.
5. Зарегистрируйся. Чтобы перенести прогресс со старого сайта, нажми на свой логин в шапке → «Загрузить из файла» → выбери файл из `_private/`.

Регистрация открыта всем, кто знает адрес. Чтобы закрыть её кодом, добавь в Render переменную `INVITE_CODE`.

Бесплатный сервис засыпает после 15 минут без посетителей и просыпается около минуты. Данные при этом не теряются: они в Turso.

### Проверка, что сайт подключён к базе

Открой `https://АДРЕС-САЙТА/healthz`. Правильный ответ: `"db":true,"store":"turso"`.

- `"problem":"db_not_configured"`: в Render не задан `TURSO_DATABASE_URL`. Так бывает, если сервис создан как обычный Web Service, а не через Blueprint: тогда `render.yaml` не читается. Добавь обе переменные в разделе Environment.
- `"problem":"db_bad_token"`: `TURSO_AUTH_TOKEN` не задан или не подходит к этой базе.

Пока база не подключена, сайт никого не впускает и прямо пишет об этом: работать с временным файлом он отказывается, потому что на Render такой файл стирается при каждом засыпании.

## Локальный запуск

```bash
npm install
```

```bash
npm run dev
```

Сайт откроется на http://localhost:3000. Без переменных окружения он работает с локальным файлом `data/cahier.db`, настоящая база не затрагивается.

Чтобы локально работать с настоящей базой, скопируй `.env.example` в `.env`, впиши токен и запусти:

```bash
node --env-file=.env server.js
```

## Переменные окружения

| Имя | Зачем |
|---|---|
| `TURSO_DATABASE_URL` | Адрес базы `libsql://…`. Если не задан, используется локальный файл |
| `TURSO_AUTH_TOKEN` | Токен доступа к базе. Секрет: не клади его в репозиторий |
| `INVITE_CODE` | Если задан, регистрация только по этому коду |
| `MAX_USERS` | Предел числа аккаунтов, по умолчанию 200 |
| `PORT` | Порт; Render задаёт его сам |

## Забытый пароль

Почты у аккаунтов нет, поэтому пароль сбрасывает владелец со своего компьютера. Нужен файл `.env` с адресом и токеном базы:

```bash
node --env-file=.env scripts/reset-password.js ЛОГИН
```

Скрипт напечатает временный пароль и завершит все сессии этого человека.

## Пересборка уроков

Правки вносятся в `content/*.py`, затем:

```bash
python3 content/build_data.py
```

Нужен пакет `openpyxl`. Расписание берётся из `content/plan.xlsx`.
